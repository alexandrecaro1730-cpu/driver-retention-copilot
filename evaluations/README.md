# Evaluation Evidence

This directory contains machine-readable proof that the system enforces policy and self-corrects.

## Deterministic end-to-end trace

`maria_self_correction.json` is generated by `python -m scripts.generate_eval_trace`. It injects an
unsafe £50 airport proposal into the normal orchestration flow. The deterministic Compliance Critic
rejects it, the Strategist revises it to £25 using `INC-001`, and the Critic approves the second pass.
The trace also exposes the context resolver, repositories, diagnostic extraction, incentive tool,
policy RAG, ledger lookup, Strategist, Critic, and conversation memory as separate steps.

## Human-mediated LLM trace

`manual_self_correction/01_rejected.json` records a schema-valid model proposal using restricted
`INC-002` at £50. The Critic rejects it under policy clause B.1.

`manual_self_correction/revision_request.json` is the exact revision bundle generated from those
findings.

`manual_self_correction/02_corrected.json` records the corrected model response using `INC-001` at
£25 and the final deterministic `APPROVE` decision.

These artifacts are recommendations and evaluations only. They do not represent an issued payment.
